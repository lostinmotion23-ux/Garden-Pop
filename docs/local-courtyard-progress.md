# Local courtyard continuation — 2026-10-21

The user chose **warm dusk, as in the concept**. The first playable courtyard
iteration is implemented locally and included in the GitHub save. It has not been published to Project 0.

The scene now has a seamless procedural 360-degree dusk/grove dome, a rounded
paved terrace, curved stone enclosure and retaining walls, a shallow animated
pond, a short waterfall, emissive garden lanterns and cherry trees framing the
sides. `src/experience/game/garden-theme.js` controls its palette and lighting.
`courtyard.js` builds the new environment; `botanical.js` integrates it. The
illustration remains an art direction reference: this procedural version does
not reproduce its detailed planting and stonework.

Rules, 20/19-column spacing, six starting rows, animal assets, rewards, exterior
and avatar are unchanged. No extra lights, reflection passes or refraction
passes were added. Water animation uses material shaders and existing normals.

## Windows setup

Run commands from the repository root. Install Node 24 and the project
dependencies before starting the playable local game with:

```powershell
.\scripts\dev-local.cmd
```

Then open `http://127.0.0.1:5173/game.html`. The root URL is the separate exterior.
With Node installed normally, `npm run dev` also works.

Relevant browser scripts now use Playwright Chromium, with the cloud's system
Chromium fallback and an optional `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` override.
For a browser installation kept in the repository's ignored `.local` folder, set:

```powershell
$env:PLAYWRIGHT_BROWSERS_PATH = "$PWD\.local\playwright"
```

Use `.local\node-v24.20.0-win-x64\node.exe` for node commands if it is not on PATH.
The new capture command is `npm run render:game:stage2`; it requires the replay
generated by `npm run check:game`. Original Stage 1 comparison images are kept.
