# Avatar anatomy foundation

The base topology and female target are CC0 assets from MakeHuman, not its AGPL
application code. Their headers explicitly state their September 2020 CC0 release.
See the included `LICENSE-CC0.txt` and the upstream license description:
https://github.com/makehumancommunity/makehuman/blob/master/LICENSE.md.

Sources retrieved 2026-10-20 UTC:

- `head-foundation.obj`: https://raw.githubusercontent.com/makehumancommunity/makehuman/master/makehuman/data/3dobjs/base.obj
- `female-young.target`: https://raw.githubusercontent.com/makehumancommunity/makehuman/master/makehuman/data/targets/macrodetails/caucasian-female-young.target
- `LICENSE-CC0.txt`: https://raw.githubusercontent.com/makehumancommunity/makehuman/master/LICENSE.ASSETS.md

Only the head and hand topology are used. The revised character proportions,
facial sculpt, hair, clothing, accessories, UV atlases, facial paint, skeleton and
animation integration were authored for the Garden Muse revision.

The body helper meshes and unused anatomy in the source OBJ are not included in
the avatar. Both published-format GLBs show the fully clothed character only.
